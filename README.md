# Portfolio de Jervis Bossou

Site personnel d'administrateur systèmes et réseaux : https://jervis736.github.io

Site statique (HTML + CSS, sans dépendance) publié avec GitHub Pages.

## Modifier le site

- Le contenu est dans `index.html`, le style dans `assets/css/site.css`.
- Pour mettre à jour le CV, remplacer `assets/resume/cv.pdf`.
- Chaque `git push` sur la branche principale met le site en ligne en une à deux minutes.
